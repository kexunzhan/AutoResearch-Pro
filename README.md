# AutoResearch-Pro 🚀

**AutoResearch-Pro** 是一款基于多智能体（Multi-Agent）架构的深度调研引擎。它通过长链条推理技术，将复杂的搜索任务转化为结构化的行业研报。

### 🌟 核心特性
- **Multi-Agent Collaboration**: 采用 Supervisor-Worker 模式，实现多任务并行处理。
- **Long-chain Reasoning**: 自动将模糊的需求拆解为具象的逻辑链路。
- **Self-Correction**: 内置 Analyst Agent 对搜索结果进行逻辑自洽性检查。

### 🛠 技术栈
- **Language**: Python 3.10+
- **Orchestration**: LangChain / LangGraph
- **LLM Support**: Xiaomi MiMo (Mistral/Llama based), GPT-4, Claude 3.5

### 🚀 快速开始
1. 克隆仓库: `git clone https://github.com/yourname/AutoResearch-Pro.git`
2. 安装依赖: `pip install -r requirements.txt`
3. 运行: `python main.py`
